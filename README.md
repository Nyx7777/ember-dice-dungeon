# 骰子地下城 · 余烬之旅

面向手机竖屏的单人骰子肉鸽 Demo。当前可完整游玩七层路线，包含一次幕末 Boss 战。原创几何插画和中文界面，无账号、无业务服务器、无外部素材请求。

## 运行

环境：Node.js 24.14.0、npm 11.9.0（开发实测）。首次安装：

```powershell
npm.cmd install
npm.cmd run build
npm.cmd run dev
```

浏览器打开 <http://localhost:4173>。安装依赖后也可运行 `启动Demo.cmd`。关闭启动命令窗口会停止本地服务器，不影响 GitHub Pages 在线版。构建产物位于 `dist/`。

手机与电脑连接同一个 Wi-Fi，在手机浏览器打开 `http://电脑的局域网IP:4173`。可以用 `ipconfig` 查看 IPv4 地址。是否能访问取决于本机防火墙和网络隔离；未自动调整系统防火墙。普通局域网 HTTP 可以在线试玩；PWA 缓存需要 localhost 或 HTTPS 安全上下文。

## 如何玩

1. 点击「点燃余烬」，进入当前层可选节点。
2. 首次投掷六骰；点击骰子保留，最多普通重掷两次。
3. 点击「收手」，选择技能并预览、确认消耗；一回合最多两个不同技能，各用各的骰子。
4. 首招前可以使用战术牌；第二招后敌人自动行动，也可手动结束回合。
5. 战后选一份构筑奖励，经过祭坛或商店、营地，最终挑战铸命者。

例如剑剑剑盾盾焰，可以重斩（剑剑剑焰）＋架盾（盾盾）。查看敌人意图再决定是否重掷。没有好组合时，可用应急防守获得 3 格挡并直接结束回合。

## 已实现内容

- 余烬骑士、6 技能、12 个互斥升级分支、4 类 6 张战术牌。
- 七层路线、4 普通敌人、精英督军和铸命者。
- 12 遗物、骰面改造、三选一奖励、商店、祭坛、营地。
- 跨战斗生命和金币、统计结算、失败重开。
- 每个有效动作保存完整状态与 RNG；导出、校验导入、版本保护。
- 首次成功缓存后离线继续，快速模式、减少动态效果、可关闭的操作音效。
- 六面 3D 骰子旋转、落地回弹，保留骰子保持静止；敌我受伤闪烁、震动、伤害飘字和格挡提示。动画先保存结果再播放，快速模式和系统减少动态效果会简化演出。

本 Demo 的初始祝福固定为 15 金币。策划数值仍待真人平衡验证，尚未完成 5 人试玩和手机真机验收。


规则测试会先构建，覆盖固定骰面、技能消耗、战术牌、格挡、Boss、奖励和存档；包含 60 个固定种子的整局脚本模拟。浏览器测试需要先启动预览服务器，并使用系统安装的 Microsoft Edge。模拟手机尺寸不代表手机真机通过。

浏览器报告与截图生成到 `test-results/`；详见 [开发记录表](开发记录表.md)。

## 代码结构

| 路径 | 职责 |
| --- | --- |
| `src/data.ts` | 技能、分支、战术牌、敌人、遗物、路线配置 |
| `src/engine.ts` | 确定性 RNG、权威状态、动作校验、存档序列化 |
| `src/app.ts` | 页面、技能支付预览、触控、自动保存、菜单 |
| `src/effects.ts` | 只读动效计划、3D 投骰和受伤演出；不修改规则状态或推进游戏 RNG |
| `public/` | 响应式样式、入口、原创 SVG 图标与离线缓存 |
| `tests/` | 规则、模拟与真实浏览器交互验收 |
| `scripts/` | 静态构建与本地服务器 |

`dispatch` 在状态副本上校验并执行动作，失败不改变原状态。随机结果与敌人多段伤害原子提交，UI 先保存后演出。预览和取消不会修改 RNG。

## 当前限制

- 仅第一幕；完整三幕、多英雄、局外图鉴和解锁留待后续。
- 十二个遗物属于可测初值；脚本稳定通关反映自动策略下的结果，不能证明玩法平衡或玩家体验。
- 浏览器存储清理会删除本地进度，重要进度请导出。存档是本地文件，不做防作弊。
- PWA 缓存与离线恢复在桌面 Edge 的 localhost 和 GitHub Pages HTTPS 均已验收；Safari / Android Chrome 的真机安装、锁屏和切后台仍待测。
